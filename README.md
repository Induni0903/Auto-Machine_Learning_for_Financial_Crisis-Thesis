# Auto-Machine_Learning_for_Financial_Crisis-Thesis


## Overview

This repository contains the implementation developed for my Master's Thesis on **Automatic Machine Learning (AutoML) for Financial Crisis Prediction**.

The project develops an **Early Warning System (EWS)** capable of predicting systemic banking crises using economic and financial indicators. The system combines data preprocessing, feature engineering, rolling-window dataset generation, and AutoML techniques to automatically discover high-performing machine learning pipelines.

---

## Research Objective

The objective of this research is to investigate whether Automatic Machine Learning (AutoML) can effectively identify predictive models for systemic banking crises while reducing manual model selection and hyperparameter tuning.

---

## Dataset

The project uses an unbalanced panel dataset consisting of:

- **129 countries**
- **1983 – 2017**
- Annual observations
- Binary target variable indicating the occurrence of a systemic banking crisis

The explanatory variables include:

### Macroeconomic Indicators

- Real GDP Growth
- GDP per Capita
- Inflation
- Real Interest Rate

### Monetary Indicators

- Broad Money (M2) to Foreign Reserves
- Domestic Credit Growth

### Financial Indicators

- Net Foreign Assets to GDP

The crisis definition follows:

> Laeven & Valencia (2018)

## Workflow

### Step 1 – Data Preparation

The preprocessing pipeline performs:

- Loading crisis data from Stata datasets
- Missing value handling
- Data cleaning
- Country metadata integration
- Feature engineering
- GDP and land-area binning
- Stratified sampling
- Balanced train/test dataset generation
- SQLite database creation

---

### Step 2 – Rolling Window Feature Engineering

Historical information is incorporated using a rolling window of five years.

For every observation, lagged features are generated including:

- Crisis history
- GDP growth
- Inflation
- Interest rate
- Monetary indicators
- Financial indicators

This temporal representation enables the prediction models to capture historical economic trends.

---

### Step 3 – AutoML Pipeline Optimization

The project uses **TPOT AutoML** to automatically search for optimal machine learning pipelines.

The optimization process includes:

- Feature preprocessing
- Feature selection
- Model selection
- Hyperparameter optimization
- Cross-validation
- Pipeline export

---

### Step 4 – Best Pipeline Evaluation

The best-performing pipelines generated by TPOT are evaluated using:

- Classification Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC

The final pipeline is exported for future prediction tasks.
